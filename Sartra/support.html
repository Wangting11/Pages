Support

Last updated: November 5, 2026

Need help with Sartra? Check the topics below or email support@sartra.com. We usually reply within a few business days.

Requirements

  • iPhone with iOS 16 or later
  • Portrait orientation (recommended)
  • Optional: camera and photo library access for adding images

FAQ

Where is my data stored?

Photos, closet items, outfits, and diary entries are saved on your device. Sartra does not sync them to our servers by default. Use Settings → Export / Backup to create a copy you control.

How do I back up or move to a new phone?

Export a JSON backup from Settings and keep the file in Files or iCloud Drive. On the new device, install Sartra and use Import to restore. For a printable overview, try wardrobe PDF export.

Weather tags are missing or wrong

Diary weather suggestions need a network connection and location permission for forecast lookup (via Open-Meteo). You can still add or edit tags manually offline.

Photos won’t import or save

Open Settings → Sartra on iOS and allow Camera and Photos. If you denied access earlier, enable it there and restart the app.

Insights look empty

Insights need items in your closet and diary entries that reference outfits or pieces. Add a few items, log a couple of days, then open the Insights tab again.

How do I reset everything?

Settings includes a clear-data option with confirmation steps. This removes local Sartra data on the device; export first if you need a backup.

Reporting a problem

When you email support, please include:

  1. iPhone model and iOS version
  2. Sartra version (Settings → About)
  3. What you expected vs. what happened
  4. Screenshots if possible (no need to send private photos)
